## 测试1

模型GLM\-5\.2\-FP8，在单机 8 × NVIDIA H200上部署，资料作者：**深联DeepLink（上海人工智能实验室）**

\*\*我们使用 [EvalScope](https://link.zhihu.com/?target=https%3A//github.com/modelscope/evalscope) 构造 5 轮对话：第一轮输入 16K Token，每轮最多输出 1K Token，后续每轮新增 2K Token。\*\*总请求数和并发数均为 16。这类 Workload 具有长上下文、高 MTP 接受率和高 Prefix Cache 命中率等特点，适合用于观察 Agentic 多轮任务下的性能。

```Bash
evalscope perf \  --model "${MODEL_NAME}" \  --url "${API_BASE_URL}" \  --api openai \  --dataset swe_smith \  --tokenizer-path "${TOKENIZER_PATH}" \  --max-tokens 1024 \  --multi-turn \  --min-turns 5 \  --max-turns 5 \  --dataset-args '{"first_turn_length": 16384, "subsequent_turn_length": 2048}' \  --num-workers 1 \  --extra-args '{"ignore_eos": true}' \  --number 16 \  --parallel 16 \  --rate 16 \  --seed 1024
```

LMDeploy 的启动配置如下。

```Bash
lmdeploy serve api_server "${MODEL_PATH}" \  --backend pytorch \  --server-port "${PORT}" \  --model-name "${MODEL_NAME}" \  --tp 8 \  --quant-policy fp8 \  --max-batch-size 64 \  --cache-max-entry-count 0.9 \  --speculative-algorithm deepseek_mtp \  --speculative-num-draft-tokens 5 \  --enable-prefix-caching \  --reasoning-parser default \  --tool-call-parser glm47 \  --trust-remote-code
```

从 Baseline 到最终版本，**Output Throughput 从 678\.74 tok/s 提高到 916\.59 tok/s（\+35\.04%），平均 TPOT 从 18\.14 ms 降到 13\.16 ms（\-27\.45%）。**

参考链接https://zhuanlan\.zhihu\.com/p/2079300963802863518
